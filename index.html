// WHAT TWO TWEAKS CHANGE

Two tweaks, explained

// MENU DELAY SETTING

Submenu Delay

Windows waits 400 ms before it opens a submenu when you hover over it (the MenuShowDelay value). The Menu delay tweak sets it to 20 ms. This is a setting, not a measured speed-up.

// HIBERNATION FILE

Hibernation file

Turning off hibernation (and Fast Startup) deletes hiberfil.sys, a file Windows keeps on the system drive. Its size depends on your RAM. Hibernate stops working until you turn it on again, for example with Restore.

Illustration only: the real size of hiberfil.sys depends on your PC.
